# 私専用の音楽設計原則 v1 — 参照作品の重点分析から

作成: 2026-10-22（Claude Code セッション）。対象: ユーザーが挙げた 16 件の参照作品・区間。
目的: 作品の模倣ではなく、**ユーザーが何に反応しているか** を抽出し、今後の制作に再利用できる設計原則へ変換する。
このセッションでは曲を作らない。

> **読み方の注意**
> - Claude は音を聴けない。以下の「観測」は音響解析（RMS / spectral centroid / 帯域比 / onset / ステレオ幅・相関 / pyin ピッチ / クロマ→コード推定）と
>   スペクトログラム画像の読み取りによる。**主観評価欄はすべて「聴取なし・推定」**。
> - 数値の根拠は `research/reference_analysis/<曲>/`（`overview.png`, `seg_*.png`, `summary.json`, `seg_*.json`）。
>   再計測は `tools/ref_analysis/`（README 参照）。
> - コード推定はミックス全体のクロマからのテンプレート照合で、ベース音やボーカルに引きずられる。**和声は「推定」**として扱う。
> - 時刻は取得した音源（niconico の配信音声）基準。動画によってはイントロの無音・編集でずれる可能性がある。

## 1. 重点分析の選定（6 作品 7 区間）と理由

| 優先 | 作品・区間 | 選定理由 |

## 2. 作品・区間ごとの分析（観測 → 解釈 → 再利用仮説）

### 2.1 夕凍み（雪歌ユフ）— 最重要

全体: 推定 123 BPM、A major / E major / C# minor の間を揺れる（クロマ上位 3 位）。**極端に暗く帯域が狭い**ミックス
（2–6 kHz 比 3%、6 kHz 以上 1.4%、250 Hz–2 kHz が 73%、centroid 平均 1.9 kHz）。無音（< −50 dBFS）が曲の 6.6%。
つまり「ローファイで、音が消える瞬間を恐れない」曲。

#### 事例 A: 30–34 s（小さな「引き→揃う」）
| 時刻 | 観測 |
|---|---|
| 30.0–32.2 | **C#5 の純音 1 本だけ**が 2.19 s（ピッチ揺れ 1 cent、ほぼモノ、250 Hz–2 kHz 帯のみ） |
| 31.5 | 0.5 s に 7 回の短い onset（クリックの連打） |
| 32.0–33.3 | レベル −10 dB、**ステレオ幅 0.99 / L-R 相関 0.01** = 直接音が消え残響だけが残る |
| 33.4 | 全帯域が同時に戻る（低域比 0.42、centroid 2.9 kHz、−12 dB） |

#### 事例 B: 56–112 s（本命の「崩壊 → 引き → 再整列」）
| 段階 | 時刻 | 観測（どのパラメータが動いたか） |
|---|---|---|
| 壁 | 56–69 | RMS −12.5 ±1 dB で平坦、onset 包絡 ≈ 1 で平坦（トランジェント無し）、centroid 2.7 kHz。持続音は C5 → 66–68 s で C#6 へ上がる |
| **崩壊の開始** | 69.5 | 最初の「穴」（RMS −5 dB の欠落） |
| **崩壊** | 70–89 | 0.3–0.5 s おきに 10–12 dB の**ゲート状の穴**、ステレオ幅が 0.1↔0.7 で**明滅**、1 秒ごとの centroid 標準偏差が 500 → 1250 Hz に増大（音色が暴れる）、onset の 16 分グリッド乖離 0.2–0.3（≈ ランダム）。**和声は A major ダイアトニックのまま継続**（F#m9 / Eadd9 / Dmaj7 / Bm）。テンポ・ピッチ・和声は壊れず、**時間（ゲート）・定位・音色** が壊れる |
| 低域だけ残る | 86–89.5 | 低域比 0.3 → 0.9、centroid 2.1 k → 0.3 kHz（ローパスが閉じていく） |
| **引き** | 89.5–91.3 | 1.8 s で −14 → −65 dB、幅 1.0 / 相関 0（残響のみ）、onset 0 |
| **再整列（空間と帯域）** | 91.4 | C#5 一音（1.17 s、揺れ 0）→ 92.5 s 以降 **完全モノ（幅 0.00、相関 1.0）・帯域 250 Hz–2 kHz のみ（帯域比 1.00）**、レベルは −11 dB に復帰、onset は弱い（≤ 1.5）。和声 F#m7 / Esus2 で 19 秒静止。「遠くのラジオ／壁越し」状態 |
| 真の無音 | 109.5–111.3 | −90 dBFS、1.3 s（110.5 s に微かな広いヒス） |
| **再整列（時間と帯域）** | 111.5 | ステレオ（幅 0.2–0.4）・全帯域・規則的 onset（強度 2.0）で全員戻る。Bm9 → Aadd9 → A |

#### 事例 C: 164–195 s（終端の「開放 → 抜ける」）
E5 を **22.5 秒**持続（揺れ 3 cent）。その間、幅 0.07 → 0.00（点へ収束）、他の音が消え（250 Hz–2 kHz 比 1.00）、
−11.8 → −9.0 dB と **ゆっくり 3 dB クレッシェンド**。186.7 s で **フェードではなく瞬断**（−80 dB）、その後 9 秒の微かな広いヒス（centroid 4.7 kHz）。

#### 解釈
- 「崩壊」は **音程・和声・テンポを壊さない**。壊すのは **振幅ゲート（時間の穴）・定位の明滅・音色の暴れ** の 3 つ。だから不安だが音楽として崩れない。
- 「引き」は 3 段階: ①ローパスで上から消す → ②レベルを 1.5–2 s で落とす → ③直接音を消して残響だけ残す（幅↑・相関→0）。
- 「揃う」は 2 種類ある。**空間の整列**（全部がモノの一点へ＝ 91.4 s）と **時間・帯域の整列**（グリッドと全帯域が戻る＝ 111.5 s）。
  この曲は両方を 20 秒ずらして使い、その間に真の無音 1.3 s を挟む。
- 開放は「一音を長く・点に集め・少しずつ大きく・瞬断」。残るのはヒス（空気）。映像参考 16 の「静止後にカメラだけ慣性で動く」に対応するのは
  **瞬断後に残るヒスと残響** である。

#### 再利用仮説
- H-Y1: 崩壊は「ゲート穴の密度」「幅の明滅」「centroid 分散」の 3 本のオートメーションで作れる（和声は固定）。
- H-Y2: 引きの説得力は **残響だけが残る 1–2 秒**（幅 ≈ 1、相関 ≈ 0）で決まる。残響が無いとただのミュート。
- H-Y3: 再整列の前に **モノ・狭帯域の「遠い版」** を置くと、全帯域復帰の快感が増す（対比が「距離」として知覚される）。
- H-Y4: 真の無音は 1–1.5 s が目安（この曲 1.3 s、flat soda 1.5 s）。

### 2.2 flat soda (vocal chop version)（葛駄夜音）

全体: 推定 129 BPM、E major。平均 −28 dBFS と小さく、無音 8.6%。高域はほぼ無い（6 kHz 以上 1.3%）。

| 時刻 | 観測 |
|---|---|
| 0–1.5 | 無音 |
| 2.0–7.5 | **声だけ**（250 Hz–2 kHz 比 0.97–0.99、低域・高域なし）、−30 dB |
| 7.5–9.0 | **残響だけの間 1.5 s**（−60 → −72 dB、幅 1.1、相関 −0.5） |
| 9–15 / 15–17 | 2 フレーズ目 → 同じ 1.5–2 s の間（E5 が残響の中で伸びている） |
| 17.0 | 初めて高域を含む要素（2–6 kHz 比 0.19、6 kHz 以上 0.10）＝ chop 開始。ここが「一度歌った後に流れが変わる」点 |
| 17–45 | **chop と歌唱が約 2 小節単位で交替**。16 分グリッドからの乖離: chop 区間 0.08–0.12（グリッドに乗る）、歌唱区間 0.31–0.40（グリッドと無関係） |
| chop の音高 | G#5（MIDI 83–84）など**歌唱より 1 オクターブ以上高い**。歌唱は E4 中心 |
| 歌唱の長音 | 0.6 s 以上の長音 12 本が**すべて E4（主音）**、揺れ 6–21 cent（ビブラートほぼ無し）、**同じ音を 0.02–0.3 s の隙間で再発音**（「ううううう」） |
| 和声 | E / Esus2 / Eadd9 / Emaj7 が静止（E ペダル）。動くのは Bsus4 ⇄ Esus4 程度 |
| 92.0–93.5 | 曲中の**完全無音 1.5 s** → 94 s に声から再入場（低域は 95.5 s から） |

#### 解釈
- 「ゆったりした歌い方」の正体は **主音 1 音の反復 + 静止和声 + 母音の長さ** で、ピッチの動きではなく **発音の間隔と長さ** が旋律になっている。
- chop と歌唱の境界は「グリッド上 / 外」と「1 オクターブ上 / 下」の **2 軸で同時に** 切り替わる。だから境界が気持ちいい。
- フレーズ間の間は「無音」ではなく **残響だけの 1.5 s**。

#### 再利用仮説
- H-F1: 主音ペダル上で **同音反復 + 長母音** だけでフレーズを作り、間を残響 1.5 s にする（メロディを「置く」）。
- H-F2: chop 区間は 16 分グリッド固定・+12〜+16 半音、歌唱区間はグリッド非依存（人間的なタイミング揺れ 20–40 ms 以上）。2 小節交替。
- H-F3: 「流れが変わる」は **新しい帯域（高域）の初出** で作れる（レベルや和声を変えなくてよい）。

### 2.3 Grief（初音ミク）

全体: 推定 117 BPM、F major。サブ低域 18% と重い。

| 時刻 | 観測 |
|---|---|
| 0–1.0 | 無音 → **息／空気ノイズ**（flatness 0.22、centroid 3.7 kHz、−80 → −56 dB） |
| 1.4 | **最初の一声（推定）: F4（主音）の持続音**、−39 dB と小さく、**アタック無し**（onset 包絡 < 0.5）、**幅 1.0–1.3・相関 ≈ 0**（巨大な残響空間）、250 Hz–2 kHz のみ。8 分音符相当の微かな脈動 |
| 1–6 | 和声 Fmaj7（主音 F の上に maj7 の E が触れる） |
| 7.0 | 低域（F2 のベース）が入る。−33 → −28 dB |
| 17.7 | ドラム・サブが入り **+10 dB の段差**（−29 → −19 dB） |
| 294–297.5 | 終端: **F5 が 3.55 s 残響の中で鳴り残る**（幅 1.05）。冒頭 F4 の 1 オクターブ上で閉じる |

#### 解釈
- 「最初の一声で感情が動く」の条件は、声の表現以前に **①無音 ②息 ③一音だけ ④巨大な空間 ⑤小音量 ⑥アタック無し ⑦主音 + maj7 色** が揃っていること。
  **声が「晒されている」状態** が感情の正体の可能性が高い。
- 「伸びやかな音」は、**周りに何も無い帯域（250–2 k 以外が空）** と **相関 0 の広い残響** で「伸びて」聞こえる。音源の長さだけでは足りない。
- 曲全体が **F4（冒頭）→ F5（終端）** で、同じ主音をオクターブで閉じる。

#### 再利用仮説
- H-G1: 曲頭は「無音 1 s → 息ノイズ 0.5 s → 主音の長音（アタック 0、幅 ≥ 1.0、−35〜−40 dBFS、他パート無し）」。
- H-G2: 伸びる高音の直後は **相関 0 の残響 ≥ 2 s** を確保し、他パートをその帯域から退かせる。
- H-G3: ユーザーが挙げた「低音 → 急に高音へ抜ける → 長く伸びる → 反響 → 別の低い声が重なる → 共振 → すっと抜ける」の構成は、
  ミックスからの自動ピッチ抽出では声を追えず（ベース・パッドに引きずられる）**未確認**。声ステムか耳での時刻指定が必要（§4）。

### 2.4 a day in the loop.（重音テト）— 前奏

| 観測 | 値 |
|---|---|
| 入り方 | 1.5 s の無音のあと **フェード無しで −22 dB に直接**入る |
| スペクトル | 60–250 Hz 比 0.45–0.80、250 Hz–2 kHz 0.2–0.55、**2 kHz 以上はほぼ 0**（centroid 600–1200 Hz）。暗く暖かい |
| 音数 | onset 2–4 / 秒、IOI 変動係数 0.76（ドラムのグリッドではない、アルペジオ／ピアノ的な不均等） |
| 幅 | 0.5–0.7（広い） |
| 和声 | 推定 D → G(sus2/add9) → A → Bm7 のループ（I–IV–V–vi、1 小節 1 コード、99 BPM で 2.4 s）。ベースは F#2 / G2 / B2（D/F# で始まる） |
| 速度 | ループを約 3 周（11 小節 ≈ 26 s）してから 27.5 s でドラム＋サブ、レベル +8 dB |

#### 解釈
「静かな入り方」は **小音量ではなく「高域が無い」** ことで成立している（レベルは −22 dB と普通）。
聴き手は 1 コードループを 2–3 周聴いて曲の重力を覚え、そこで初めてリズムが入る。

#### 再利用仮説
- H-D1: 前奏は 2 kHz 以上を空にする（LPF ≈ 2 kHz 相当）だけで「落ち着き」が出る。音量は下げすぎない。
- H-D2: 入りは 4 コードループ × 2–3 周（20–30 s）を目安に、リズム入りで +6〜+8 dB。
- H-D3: 音の間は「グリッド上の休符」ではなく **不均等な onset 間隔（IOI cv ≈ 0.7）** で作る。

### 2.5 幻☆ — 最初の一音

| 時刻 | 観測 |
|---|---|
| 0.0–0.1 | 単発の広帯域クリック（onset 強度 14）→ 0.4 s まで無音 |
| 0.4–1.4 | **硬いヒット 5 連打**（onset 9–17、flatness 0.3 = ノイズ的）、間隔 0.15–0.20 s。1.2–1.5 s に 300 → 100 Hz の下降グライド（テープストップ様） |
| 1.45 | テクスチャ入場: **幅 0.8–0.9・相関 0.1–0.4（非常に広い）**、アタックは柔らかい（onset 2–5）、250 Hz–2 kHz 0.65–0.8、6 kHz 以上 0.04–0.14、**低域・サブはほぼ 0（12 s まで低域が無い）**、centroid 3–4.4 kHz |
| 和声（推定） | Gmaj7 → Em7 → **F#7** → F#m7 → Dmaj7 / Bm7 → **Am7(6)** → **D7** → Gmaj7 → **F#7** → D / Bm7 → Am …（D major） |
| 12.2 | ドラム入場 |

#### 解釈
- 「おしゃれ」の正体は和声: ダイアトニックな D major に **セカンダリドミナント（F#7 = V/vi、D7 = V/IV）と借用 v（Am7）** が 1–2 小節ごとに混ざる、
  いわゆるネオソウル／シティポップ型。さらに全部が 7th 系（maj7 / m7 / 7）。
- 「最初の一音で雰囲気」は **雰囲気の前に短い「硬い」前置き（クリック → 5 連打 → 下降グライド）** があって、
  1.45 s に **広く・柔らかく・低域の無い** テクスチャへ切り替わる **対比** で作られている。最初の 1.4 秒は「構え」。
- 低域が 12 秒無いことで、テクスチャが「浮いて」聞こえる（Grief / flat soda の冒頭と同じ「下が無い」設計）。

#### 再利用仮説
- H-M1: 曲頭 = 硬い前置き（≤ 1.5 s、ノイズ的・モノ）→ 広い柔らかい和音（幅 ≥ 0.8、低域なし、7th 系）。
- H-M2: おしゃれさ = セカンダリドミナント 1 個 + 借用和音 1 個を 4 小節に入れる。全コードに 7th/9th。

### 2.6 愛しているんだ feat. flower / John Gorilla Remix — イントロ

| 観測 | 値 |
|---|---|
| 0–19 s の帯域 | 低域ほぼ無し（60–250 Hz ≤ 0.1、サブ 0）、明るい（centroid 2.3–3.4 kHz）、毎拍（0.6 s）に硬いクリック |
| 和声（推定） | 1 小節 1 コード: **Eb(add9) → Gm7 → F6 → F**（F major の bVII → ii → I → I、ミクソリディアン的） |
| 声（推定） | 9.6 s 付近から D5–A5 域の持続（1 s 前後）が検出されるが、レベルは −20 dB と伴奏に埋まり気味。声の同定は**未確認** |
| 18.5 | 0.5 s の穴（残響のみ、幅 0.72）→ 19 s にベース＋サブが一気に入り +7 dB |

#### 解釈
声そのものの「弱さ・会話性」は自動解析では取れない。取れたのは **声を「弱く」聴かせる伴奏側の条件**: 低域が無い、毎拍のクリックが時間を刻む、
和声が bVII で始まる（解決しない浮遊）、声が伴奏より小さい。歌詞側の「思考実況」は §3.9 で扱う。

### 2.7 Animators Rainbow 2020 — 「遠くへ進む」

| 観測 | 値 |
|---|---|
| パルス | 129 BPM、四つ打ち、テンポ安定（局所テンポの変動 0.145、最小）。サブ 30% |
| 長期トレンド | centroid が 1 kHz（0:00–0:15）→ 2 kHz（0:50）→ 2.5–3 kHz（2:10〜）と **90 秒以上かけて上昇** |
| 100–140 s | 和声は **Fmaj7 / Dm9 が 40 秒静止**。111–126 s ブレイク（サブ 0–0.2、centroid 1.2 kHz、幅 0.5–0.8 と広い）→ 126 s サブ復帰 → 133 s で centroid +1.5 kHz（サビの明るさ） |

#### 解釈
「目的地が見えない長い道」= **和声が動かない + パルスが一定 + スペクトルだけが非常にゆっくり開く**。到達は和声ではなく **帯域（サブ復帰・高域の段差）** で表す。

#### 再利用仮説
- H-A1: 疾走感は BPM ではなく「一定パルス × 静止和声 × 単調増加するパラメータ（centroid / 幅 / 高域比）」。
- H-A2: 到達点は和声解決ではなく **サブの復帰 + 高域の段差**。

### 2.8 音源を取得できなかった作品（記述 + 知識ベースの仮説。要検証）

- **gloomy（yosumi & gaburyu）**: ユーザーの語彙（夜・都市・人の多さ・ゴミ・一時的な街・焦燥・思考が広がる）を設計に写すなら、
  ①「人の多さ」= 多数の小さな音（細かい hi-hat / クリック / ボイスの断片）が **個々には小さく、総量で密度** を作る、
  ②「無機質なのに心地よい」= 冷たい音色（短い減衰、ノイズ混じり）× 暖かい和声（m7 / maj7 の静止）、
  ③「思考が広がる」= 時間とともに **ステレオ幅と残響が増える** 一方向のオートメーション、
  ④「焦燥」= 一定の速いサブディビジョン（16 分）がずっと鳴るが、アクセントは不規則。**要音源確認**（Windows 側で取得して `tools/ref_analysis` にかける）。
- **花火 (instrumental)**: 「綺麗なピアノ → 突然暴力的 → また綺麗」は、§2.1 事例 A（純音 → クリック連打 → 残響だけ → 全帯域ヒット）の
  構造と同型と仮定。打撃音は **ピアノの帯域（250 Hz–4 kHz）と被らない超低域 + 超高域** に置き、ピアノの残響は切らずに打撃音の下で鳴らし続ける
  （「綺麗」が消えないことが共存の条件）。
- **Snowing 0:53〜（Jacob's Piano）**: 「一音 → 間 → 一音 → 長音」はソロピアノの基本形。計測すべきは **IOI の分布**（長い間と短い間の 2 峰性）と
  **ペダル残響の長さ**。flat soda の「同音反復 + 残響の間」と同じ原理と仮定。
- **昔の巡音ルカ（JBF / My Baby Blue / Gravity=Reality）**: ユーザーの語彙「ハスキー・大人・柔らかい・少し人工的・包み込む」は、
  音響的には ①2–4 kHz のプレゼンスが控えめ、②息成分（4–8 kHz のノイズ）が多い、③アタックが柔らかく子音が弱い、
  ④当時のエンジンのフォルマント補間による「少し人工的」な揺れ、⑤低めの音域（A3–E5）。合成ボーカルを使う際のターゲットとして §3.9 に記載。
- **シュガーバイン（VY1V4）**: 「子音の出方・韻・語尾」= 子音の長さと子音前の微小な無音、語尾の減衰形。声ステムが無いと計測不可。
- **2021 sakuga archive**: 非公開のため取得不可。「言葉より先に感情」= Grief と同じ「晒された一声」仮説に含める。
- **演出参考（止め絵 → カメラだけ慣性）**: 音楽への変換は §3.3 P-11（瞬断 + 残響・定位の残留運動）。

### 3.5 メロディ研究へ渡す知見

- **主音の長音から始め、主音で閉じる**（Grief F4 → F5、flat soda E4、夕凍み E5）。頂点は「別の音」ではなく「同じ音のオクターブ上」でよい。
- **同音反復**は旋律として成立する（flat soda: 長音 12 本すべて E4、隙間 0.02–0.3 s）。変化はピッチではなく **長さ・間隔・母音** に置く。
- 「一音 → 間 → 一音 → 長音」の間は **グリッドの休符ではなく不均等な IOI**（a day in the loop の IOI 変動係数 0.76、歌唱区間のグリッド乖離 0.3–0.4）。
  `candidates` の motif 変奏に **タイミング揺れ（timing jitter）と長さの再配分** を変奏 op として追加する価値がある。
- 高音への抜けは **跳躍そのものより、抜けた先の帯域が空いていること** が効く（Grief）。lead の上に何も置かない。
- 既存 MUSIC_SPEC の P4（跳躍後の順次）/P6（最高音温存）は維持。P7（3+3+2 シンコペーション）は本嗜好とは別系統で、曲ごとに選ぶ。

### 3.6 サウンドデザイン研究へ渡す知見

- **「透明」= 低域を抜く + 相関 0 の残響**、**「静か」= 高域を抜く**。両者は別のフィルタで、別の感覚を作る（V-7）。
- 残響は「空間」ではなく **「間」の素材**。直接音をミュートしたときに残る 1–2 s が設計対象。リバーブの decay は ≥ 2 s、pre-delay 短め、幅最大。
- **狭帯域モノの「遠い版」**（BPF 250 Hz–2 kHz、幅 0、レベルは落とさない）は再整列前の有力な素材（夕凍み 91–110 s）。mix overlay として実装可。
- 打撃音（暴力性）は **flatness ≥ 0.3 のノイズ的トランジェント + サブ** で、綺麗な音の帯域を避ける（P-09）。
- 曲頭の「硬い前置き」（幻☆: クリック → 5 連打 → 下降グライド、合計 1.4 s）は、その後の柔らかい広がりを際立たせる。
- 終端のヒス（夕凍み: 瞬断後 9 s、centroid 4.7 kHz、−90 dBFS 付近）は「残留運動」の音響版。noise bed パッチを用意する。
- ローファイ（高域 1–3%）を恐れない。現行 `mix.harsh_high`（高域比 > 0.22 警告）は本嗜好では上限として緩すぎるくらいで、
  逆に **下限** は不要。

### 3.7 「崩壊 → 再整列」研究へ渡す知見

- 動かすもの / 動かさないもの（夕凍み 70–112 s の計測）:
  - 動く: timing（ゲート穴・onset の不規則化）、stereo（幅 0.1 ⇄ 0.7 の明滅 → 残響のみ 1.0 → モノ 0）、density（穴の数）、
    transient（壁では 0、崩壊で 2–5、再整列で 2）、reverb（引きで残響のみ）、silence（1.3 s）、dynamics（−12 → −65 → −11 → −90 → −15 dB）、spectral balance（LPF 閉 → 狭帯域 → 全帯域）。
  - 動かない: pitch（持続音は保持）、harmony（A major ダイアトニックのまま、再整列後も Bm9 → A）、tempo。
- 時間スケール: 崩壊 ≈ 20 s、引き ≈ 2 s、遠い版 ≈ 19 s、無音 ≈ 1.3 s、復帰は瞬時。**崩壊は長く、引きと復帰は短い**。
- 同じ文法が 3 スケールで反復（30–34 s: 4 秒版 / 69–112 s: 40 秒版 / 164–195 s: 終端版）。**曲の中で文法を 2 回以上使うと「特徴」になる**。
- 実装順の提案: ① P-06 の引き 3 段と P-07 の「遠い版 → 無音 → 全帯域」を既存の build/drop に当てる（P11 "引き算による到達感" の拡張）→
  ② P-05 の崩壊オートメーション（seed 固定の乱数）→ ③ V-1 / V-5 / V-6 の A/B。

### 3.8 リズム・疾走感研究へ渡す知見

- 疾走感の素は **パルスの一定性**（Animators Rainbow: 局所テンポ変動 0.145 で最小、四つ打ち + サブ 30%）と **単調増加するパラメータ**
  （centroid 1 k → 3 kHz を 90 s 以上かけて）。BPM は 99（愛しているんだ、a day in the loop）でも 129 でも成立する。
- 到達は和声解決ではなく **サブの復帰（126 s）→ 高域の段差（133 s）** の 2 段。
- 「焦燥」はテンポではなく **細かいサブディビジョンが鳴り続ける中でアクセントだけ不規則**（夕凍み 70–89 s のゲート穴）、
  または **毎拍の硬いクリック**（愛しているんだ）。
- 「歩く／走る／飛ぶ」の違いは、パルス密度（4 分 / 8 分 / 16 分）× 低域の有無（走る = サブあり、飛ぶ = 下なし）で表現できる仮説（未検証）。

### 3.9 ボーカル研究へ渡す知見

- **最初の一声の条件**（Grief）: 無音 → 息ノイズ → 主音の長音、アタック 0、幅 ≥ 1.0、−35〜−40 dBFS、他パート無し、maj7 の色。
  声の表現力より **晒され方** が効く。
- **長母音の同音反復**（flat soda）: E4 を 0.6–1.1 s、揺れ 6–21 cent（ビブラート無し）、隙間 0.02–0.3 s。語の途中に長音を入れる = 子音で区切らず母音を継続。
- **chop / 歌唱の 2 軸切替**（P-12）。
- **声質ターゲット（昔のルカ、知識ベース）**: 2–4 kHz プレゼンス控えめ、4–8 kHz に息、子音弱め、音域 A3–E5、少しフォルマントの揺れを残す。
  合成ボーカル導入時は「クリア」側に寄せない EQ・de-esser 方針（`instruments/` にボーカル用パッチを作る際の初期値）。
- **会話的な歌詞**: 思考実況（「〜って思った」）と同一文法の反復（「続けようと／考えようと／…」）は、音楽側では
  **同音反復 + 不均等 IOI**（§3.5）と相性がよい。反復される文法は **同じ音高・同じリズム型** に乗せ、末尾の語だけ長音にする、という割り付け案。
- 自動解析の限界: ミックスから声のピッチを安定して追えない（Grief / 愛しているんだ で失敗）。**声ステムの書き出し**（自作曲）か、
  **ユーザーの時刻指定**（参照曲）が必要。
