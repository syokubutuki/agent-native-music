# 探索「ふたりの音」: つむぎ × ずんだもん のかわいい音を広げる短い試作

## 目的
完成曲ではなく、聴き比べ用の短い試作（各 20 小節 ≈ 41 秒）を方向ごとに並べ、ユーザーが試聴ページで ★ とメモを
つけて「次に伸ばす方向」を選べるようにする。方向: 掛け合いの型 / 音色 / ほわんほわんの度合い / 音痴の量 / 声の組み合わせ。

## 守ったこと（`.claude/skills/talk-duet-song/SKILL.md` より）
- 演出（セリフ・台本）は入れない。全部「歌」の中で完結する。
- 読み上げ声に音程補正はかけない（`--mode talk` のみ。テープ揺れも伴奏だけにかけ、声は揺らさない）。
- 声は測定済みの音域内: つむぎ C#4–A4、ずんだもん A4–D#5、ニア C#4–C#5、はう F4–D#5。例外は「最後だけユニゾン」の
  ずんだもん G#4（1 半音下。二人の音域が重なるのは A4 だけなので、ユニゾンはその周りでしか作れない）。テストで確認。
- 音は 8 分中心、4 分以上は `capForTalk` が 0.3 秒以内に切る（テストで確認）。
- 同じ伴奏・同じ音量: どの試作も `produce` の master が -11 dB RMS にそろえる。グループ内では 1 要素だけを変える（テストで確認）。

## 共通の土台（songs/explore-duo/sketches.mjs）
- 場面「あまやどり」: 雨の日、軒下で二人が雨がやむのを待つ。言葉は柔らかく、擬音は雨と水（しとしと、ちゃぷちゃぷ、みずたまり）。
- A メジャー 128 BPM。intro 2（Dmaj7 | E）→ a 8 → b 8（Aadd9 Dmaj7 Aadd9 Dmaj7 F#m7 Dmaj7 E E）→ end 2（Dmaj7 | Aadd9）。
- 伴奏は「あめ あめ あめ。」v5 と同じ流儀: ビブラフォン（1・3 拍目）、パッド、丸いベース（3+3+2）、軽いキック・クラップ・シェイカー、
  オルゴールのガイド、ミックスも v5 の `meta.mix` をそのまま。
- 基準の歌（交互）: つむぎが 1 小節で問い、ずんだもんが次の小節で「〜のだ」で返す。最後は つむぎ「ふたりで」→ ずんだもん「あまやどり」。
- 和音の選び方: I（A）と IV（D）を 1 小節ずつ揺らすので、つむぎの {E4 F#4 G#4 A4} を 5 半音（4 度）上げた
  ずんだもんの {A4 B4 C#5 D5} が 1 小節後の和音にそのまま乗る → 輪唱・こだまが同じ伴奏の上で成り立つ。

## 試作一覧（ページの id は `duo-<id>`）
### 掛け合いの型（伴奏・音響は共通、歌だけ違う）
| id | 何を変えたか |
|---|---|
| form-alt | 交互（基準） |
| form-round | 輪唱: ずんだもんがつむぎの旋律を 4 度上・1 小節遅れで追いかける。同じ言葉が重なる |
| form-echo | こだま返し: つむぎの言葉の終わりを、ずんだもんが 4 度上で 2 回、小さくなりながら返す（gain 0.7 → 0.4）。ずんだもんは自分の言葉を持たない |
| form-third | 3 度のハモり: ずんだもんの返事に、つむぎが 3 度下で重なる（D5 の下だけ 6 度下 F#4。3 度下 B4 は音域外） |
| form-hocket | 1 語ずつ交互: 半小節ごとに言葉を渡しあう（あめが / ふるね / かさ / ないのだ …） |
| form-unison | 交互のまま、最後の「ふたりで あまやどり」だけ二人が同じ音（A4 のまわり） |

### 音色（歌は交互、ビブラフォンの役だけを差し替え。トレモロ・コーラス・リバーブのかけ方は同じにした）
| id | 音 | 伴奏の型 |
|---|---|---|
| timbre-vibes | ビブラフォン（基準） | 1・3 拍目に和音 |
| timbre-toypiano | トイピアノ: 金属棒（倍音 1 : 6.27 : 17.55）＋木のコツン、1 音ごとに ±9 セントの調子はずれ | 同じ型を 1 オクターブ上 |
| timbre-kalimba | カリンバ: 長く鳴る基音＋すぐ消える 5.93 倍の「チン」 | 3+3+2 の分散和音 |
| timbre-celesta | チェレスタ: ほぼ正弦波＋2・4 倍音 | 1・3 拍目、1 オクターブ上 |
| timbre-harp | ハープ: Karplus–Strong の弦（allpass で正確に調律） | 1 拍目に下からのアルペジオ、3 拍目に軽く |
| timbre-uke | ウクレレ風: 明るく短い弦 | D・DU・UDU のストローク（弦間 22 ms） |
| timbre-rain | ビブラフォン＋雨音（さーっという音＋ぽつ・ぴちゃの粒、毎秒約 9 粒、seed 固定） | 全体に 1 本の長いイベント |
| timbre-tape | ビブラフォン＋テープの揺れ（伴奏だけ: wow 0.55 Hz ±9 セント、flutter 6.5 Hz ±2.5 セント） | — |

撥弦楽器（カリンバ・ハープ・ウクレレ）を 1・3 拍目の和音で鳴らすと形にならないので、伴奏の型は楽器の流儀に合わせた
（「伴奏が同じ」の例外。音の密度は近くなるようにした）。

## 追加した機能
- `src/song/synth.mjs`: `toyPiano` `kalimba` `celesta`（共通のモーダル合成）、`harp` `uke`（Karplus–Strong、allpass 調律）、`rain`（seed 固定の雨）。
- `src/song/fx.mjs`: `tape`（wow/flutter。深さはピッチのずれ〔セント〕で指定、変調ディレイ）。
- `src/song/produce.mjs`:
  - `comp: 'toyPiano'|'kalimba'|'celesta'|'harp'|'uke'`（楽器ごとの伴奏の型は `compBar`）、`rain` / `rainBars`（1 本の長いイベント）。
  - `sections[].heta`: `'none'|'weak'|'mid'|'strong'` または `{ a, z }`。CLI の `--heta` より優先。
  - フレーズの第 3 要素 `{ gain }`（こだまのように小さく歌うフレーズ。ガイドのオルゴールはなぞらない）。
  - `meta.mix.tape`（伴奏のバスに、声が入る前にかける）。`produce` の戻り値に `stats`（差し替え数、音程のずれ）。
- `bin/song.mjs explore <dir> [--only id,…]`: `sketches.mjs` の全試作を書き出し、`measure.json`（長さ・ピーク・差し替え数・
  音程のずれ・5 帯域のエネルギー比）と `page.json` を作る。同じ譜面（各グループの基準）は 1 回だけ書き出してコピー。
- `bin/lab.mjs page --previous <公開済み index.html>`: この環境に音源が無い過去の曲（WAV は git に入っていない）は、
  公開済みページのクリップ（同じ音源パスと波形）を引き継ぐ。新しいセッションでもページを作り直し、新しい MP3 だけ送れる。
- VOICEVOX への fetch: アイドル接続が切られて "fetch failed" になることがあった → 1 回だけ再試行（talksing / voicevox）。

## 判断の記録
- 「ちゃぷちゃぷ」はエンジンが「チャ/プ/チ/ヤ/プ」と読む（2 つ目の「ちゃ」が 2 モーラになる）→ カタカナ「チャプ」で書く。
- 輪唱の初版で検査落ち: 語頭の「う」（うたおう）、高い C#5 で始まる「に」、D5 を含む「らららら」→
  「ならんで」「あめが やむかな」「みずの おと」に替えた。
- こだまの 2 回目は、休符をはさまないと 1 回目と同じフレーズにまとまって音量が下がらない → 4 モーラのこだまは 2 回目を 2 モーラにして離した。
