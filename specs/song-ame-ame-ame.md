# 曲「あめ あめ あめ。」: ボイロ（トーク音声）の掛け合いで作る、ゆるかわいい曲

## 経緯
「シュガシュガポイズン」v3 の後、ユーザー: 「歌詞を変えて、よりかわいく。音作りも変えて」。参考: https://www.youtube.com/watch?v=TN60zc08x04
→ インゲン「カニ カニ カニ。」（2021-07-25、2:51、歌: 琴葉茜・琴葉葵）。VocaDB のタグ「デュエット」「歌うソフトウェアトーク」、
ニコニコの記事見出し「カニダンスが猛烈かわいいボイロソング」「ゆるーい空気感」「心穏やカニなった」。
以前の「ボイロっぽく」は VOICEROID（トーク音声）のことだったと判明。歌詞・旋律・編曲は流用せず、核の 3 点だけ取り入れる:
1) 二人の掛け合い 2) トーク音声に歌わせる声（ボイロ曲の声） 3) ゆるくてかわいい空気と言葉遊び。

## 声: VOICEVOX のトーク音声で歌う（src/song/talksing.mjs）
- `/audio_query` で歌詞の読み（モーラ列）を取り、各モーラの pitch（ln f0）と子音・母音の長さを楽譜で上書きして `/synthesis`。
  無声化を避けるため母音は小文字（有声）に。モーラ数が音符数と合わなければエラー。
- 測定（同じ高さの「ら」×4、周期性と音量）: 使える音域 つむぎ C♯4–A4（＋D♯5）、ずんだもん A4–D♯5、はう F4–D♯5、ニア C♯4–C♯5。
  → つむぎ（低い声部）＋ずんだもん（高い声部、「〜なのだ」のくせ）。VOICEVOX の定番コンビを琴葉姉妹の位置に。
- 測定: 0.23 s 以下の音は安定（-20〜-30 dB）、0.47 s の音は息っぽく消える（-36〜-43 dB）。「ー」で伸ばしても、同じ母音を打ち直しても改善せず。
  → トーク部分は音を 0.3 s 以内に切り、残りは休符（capForTalk）。短く弾む歌い方はボイロ曲らしさでもある。
- QA（talkQa）: 音符ごとに 25 ms 窓で ±3 半音内の周期性の中央値と音量を見る（トーク音声は音間を滑らかに移るので、一定の音程は要求しない）。
  フレーズ最後の音は話し言葉の文末のように消えるので前半のみで判定、「ん」は音量を見ない。不合格のフレーズだけ同じキャラの歌唱用の声に自動で差し替え。
  v1 の最終版では差し替え 0 件（無声化しやすい「む」「う」で始まる語や 1 音だけのフレーズは、楽譜側で直した）。

## 曲（songs/ame-ame-ame/score.mjs）
- A メジャー、128 BPM、100 小節 ≈ 3:08。構成: イントロ 8 / A1 16 / サビ 16 / 間奏 4 / A2 8 / サビ 16 / ブリッジ 8 / サビ 16 / アウトロ 8
- 物語: ピンクの空から飴が降る。ずんだもん「ぜんぶ ほしいのだ」、つむぎ「むしばに なるよ」（以前の「毒と甘さ」を虫歯というかわいい毒に）。
  ブリッジは一粒をめぐる小さなけんか（ひとつ わけて / だめなのだ / えー / じょうだんなのだ / はんぶんこ）。
- フック: ずんだもんの淡々とした「あめ あめ あめ。」（同じ言葉 ×3 + 句点の間）。「せーの」で二人がそろってサビへ。
- 和音: サビ A(add9)–E–F♯m7–Dmaj7、A メロ Dmaj7–E–C♯m7–F♯m7（王道進行）、ブリッジ Bm7–E–C♯m7–F♯m7。
- 音作り（EDM 系をやめる）: マリンバ（打ち下ろし + 裏拍の刻み）、丸いベース（サイン + 三角、跳ねる 3+3+2）、軽いキック、
  シェイカー、クラップ、オルゴール（イントロとアウトロでフックを先取り/回想）、チップのリフ（間奏・ラストサビ）、
  スライドホイッスル（場面転換）、おもちゃの効果音。
- 計測: 区間 RMS イントロ -16.6 / A -11.3 / サビ -10.2 / 間奏 -15.1 / ブリッジ -12.2 / アウトロ -14.5 dB、
  低域 6.9%・中低域 25.8%・声帯域 25.8%・8 kHz 以上 0.3%（軽く明るい）。

## v2（「ころん」→「ふわり」、歌わせ方 3 方式の聴き比べ）
フィードバック: 掛け合い・場面が浮かぶ声と歌詞・明るいメロディ・ふわふわ感が好評。つむぎの「ころん」は語呂が悪い。
「読み上げの声で歌わせる」とは何か、ほかの方式と聴き比べたい。

- 歌詞: ころころ ころん → ふわふわ ふわり、てのひらに ころん → てのひらに ふわり、もう ひとつ ころん → もう ひとつ ふわり
  （モーラ数が同じなので旋律はそのまま。語尾の「ん」は鼻音で弱く、トーク音声では特に消えやすかった）。
- `node bin/song.mjs produce <dir> --mode talk|sing|hard` で歌わせ方を切り替え（ページには方式名つきで並ぶ、インストは 1 本だけ）:
  - talk: トーク音声（読み上げ用の声）に 1 モーラずつ音高と長さを指定（ボイロ曲の声。短い音、音間の滑らかな移り）
  - sing: 歌唱用の声。波音リツ（歌唱指導）の抑揚をつむぎ / ずんだもんの歌声で。softTune（揺れ 50% 残し）。長い音もそのまま歌う
  - hard: sing と同じ声で、音程を各音符に貼り付け（機械的なボカロ風）
- 3 方式の音量は揃っている（A -11.2〜-11.3 / サビ -10.3 dB）。talk 方式の差し替え 0 件。

## v3（読み上げの声質のまま機械的に / 「ふわり」→ 雨の音）
フィードバック: v2-talk の「二人がしゃべっているような雰囲気」と、v2-hard の「楽器のようにメロディに張り付く安定感」の両方が良い。
読み上げ方式の声質を残したまま機械的にしたい。「ふわり」は雨の音として合わない（モーラ数は変わってよい）。

- 歌詞: ふわふわ ふわり → ぱらぱら ぱらり（まばらに降る粒の音）、てのひらに / もう ひとつ ふわり → ぽとり（一粒落ちる音）。
  「ぽつぽつ」は「つ」がトーク音声で無声化しやすいので避けた。トーク QA は全フレーズ合格。
- 新方式 `--mode talkhard`: トーク音声で歌わせた後、TD-PSOLA（src/song/psola.mjs）で音程を補正。
  声の 1 周期ずつを 2 周期幅のハン窓で切り出し、目標音程の周期で並べ直す。スペクトル包絡（声質）は保たれ、音程だけが音符に張り付く。
  目標音程は各音符の高さ、音の境目は 12 ms で移る。検出は目標音の ±45% の範囲だけを探す（楽譜があるので誤検出が少ない）。
- 計測（実音声）: 音符内の音程の揺れ（片幅）ずんだもん「あめあめあめ」中間 4 音 ±92〜131 → ±14〜24 セント、
  つむぎ「ぱらぱらぱらり」±37〜166 → ±20〜32 セント（フレーズの最初と最後の音は立ち上がり・語尾で測定自体が不安定）。音量比 0.94〜0.95。
- テスト: 合成音声（2 フォルマント、400→470 Hz の滑り）を 392 / 440 / 523 Hz に補正して、揺れ 40 セント未満・平均 10 セント以内・音量 0.8〜1.2 倍。

## v4（「下手かわいさ」を守って強調する）
フィードバック: talkhard は声がノイズっぽくなるので不採用。talk の「少し外れて少し音痴な感じ」が、歌の得意でないキャラが
頑張って歌っているようで、聞くほど癖になる。この空気感を大切にしたい。「ぽとり」は鳥の糞のようで合わない → B 案。

- 歌詞（B 案）: てのひらに ひとつぶ / きらきら ひかる（「ひとつ」は語尾の「つ」が無声化しやすいので「ひとつぶ」、「ひと」は 8 分に）。
- 音痴の演出（`--heta none|weak|mid|strong`）: 1 回歌わせて音ごとのずれを測り（psola.noteOffsets）、
  目標ずれ = clamp(実測 × scale, ±limit) + キャラの癖 で読み上げ用の音高指定を補正して歌い直す（検査に落ちたら元の版を使う）。
  weak {0.4, ±35}, mid {0.75, ±60}, strong {1.2, ±110}。計測（533 音）:
  そのまま 中央値 35c / >50c 35% / >100c 12%、弱 16c / 11% / 3%、中 28c / 21% / 2%、強 38c / 44% / 13%。
- キャラごとの癖（meta.singers[x].heta）: つむぎ = 全体 -15c・15 ms 遅れ（控えめ）、ずんだもん = +10c・C♯5 以上 +25c・15 ms 走る（自信家）。
- ガイドメロディ: 歌メロをオルゴールで 1 オクターブ上、-33 dB でなぞる（基準があると外れが「揺れ」として聞こえる）。
- 台本: ラストサビ前に 4 小節の「challenge」。ずんだもん「いくのだ」→ B5 まで駆け上がって本当に声が裏返る（`!` で検査対象外）→
  つむぎ「おしい」→「もういっかい なのだ」→ 二人「せーの」。間奏にセリフ「えへへ」「たのしいのだ」。セリフは `say:` で、
  エンジン本来の読み（音高・長さを指定しない）で話させる。
- 曲 104 小節 ≈ 3:15。テスト 40 件。
- talkhard（PSOLA）はユーザー判断で不採用。コード（psola.mjs、`--mode talkhard`）は比較用に残し、ずれの計測（noteOffsets）は heta で使う。

## v5（演出をやめ、柔らかく「ほわんほわん」に）
フィードバック: 挑戦の場面・しゃべるターンは不要（演出は没入を現実に引き戻す）。もっと柔らかく、反響があってよい。
ほわんほわんする音響感覚、中毒的な感じ。とにかく二人のやり取りを聞き続けたい。ほかのセッションでも二人の音を広げ、ほかの曲も作りたい。

- 構成: challenge と間奏のセリフを削除（100 小節 ≈ 3:08）。`say:` / `!` の記法は機能として残す（テストは合成区間で）。
- 伴奏: マリンバの刻み → ビブラフォン（1・3 拍目で和音、長い余韻）。全セクションにパッド。
- `meta.mix`（曲ごとのミックス設定）を追加: ビブラフォン・オルゴール・ガイドに 4 分音符同期のトレモロ（128 BPM = 2.13 Hz、深さ 0.5）、
  パッドとビブラフォンにコーラス、声にも薄いコーラス、声のリバーブ 0.5（room 0.88 / damp 0.55 / プリディレイ 35 ms）、
  楽器リバーブ 0.45、クラップ・シェイカーを控えめに、6 kHz 以上を -2.5 dB。8 kHz 以上の成分 0.3% → 0.1%。
- 書き出し: 外れ方そのまま / 音痴 中 の 2 本。
- ほかのセッション向けに `.claude/skills/talk-duet-song/SKILL.md`（好み・没案・制約・新曲の作り方・広げ方）と
  `scripts/voicevox-install.sh`（空の環境で 45 秒、検証済み）を追加。CLAUDE.md から参照。

## v5 を基準として固定（再現性）
ユーザー: 「非常に完成度が高い。何回も聞きたくなる単純だがかわいらしさ、中毒性、独自性。他のセッションでも同じ雰囲気を再現したい」。
- v5 の設定（二人の声と癖、ほわんほわんのミックス、セクションの既定値）を `src/song/presets.mjs`（`yuruDuetMeta`, `DUET_SECTION`,
  `floatingMix(bpm)`, `DUET_SINGERS`）に切り出し、この曲もそれを使う形に。書き出しのハッシュが切り出し前と一致（de1b0c24…）。
- none と mid の違いを音ごとに記録（`out/work/heta-report-mid.json`）:
  つむぎ 中央値 24c → 6c、ずんだもん 18c → 19c。大きな違いは「ぱらり」の「り」（0:56 ほか、-257c → +221c、行きすぎ）、
  「むしば」の「む」（0:58 ほか、+179c → +36c）、A メロ「なにか ふるのだ」付近（0:34–0:42、ずんだもん +117〜167c → +77〜81c）。
  エンジンの応答: つむぎ 小 0.98 倍 / 大 1.58 倍、ずんだもん 0.5 倍 → mid の癖づけは均一には効いていない。

## v6（耳に残る設計: アクセント・こだま・ループ）
ユーザー: none のままでよい。記憶に残る音楽設計、耳に残るメロディを設計する方法は？ → C 案（手法を道具化し、この曲で試し、新曲は別セッション）。
- `node bin/song.mjs analyze`（src/song/analyze.mjs）: フック回数、音域、跳躍、言葉の速さ、フレーズごとのアクセントと旋律の一致。
- v5 の一致率 25%（偶然 ≒ 33%）。フック「あめ あめ あめ。」の旋律（高→低）は「雨」のアクセント、エンジンの読みは「飴」→ 掛け言葉として残す。
- A メロ・ブリッジの旋律だけを、音域とリズムを保ったままアクセントに沿わせた: A メロ 80%、ブリッジ 89%、全体 25% → 42%。サビは不変（19%）。
- サビでずんだもんの「あめ あめ あめ。」の直後（つむぎが入るまでの 6/16）にオルゴールが C#6–A5–C#6 で返す。
- アウトロの和音を Dmaj7–E–Dmaj7–E にして E で終え、オルゴールのフックで閉じる（ループでイントロの A に戻る）。
- 「はんぶんこ」（つむぎ）の「は」が E4 で無声化して検査に落ちたので F#4 に。差し替え 0 件。音痴の度合いは v5 とほぼ同じ（中央値 31c、半音以上 12%）。
