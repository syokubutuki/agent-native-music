# 曲「あめ あめ あめ。」: ボイロ（トーク音声）の掛け合いで作る、ゆるかわいい曲

## 経緯
「シュガシュガポイズン」v3 の後、ユーザー: 「歌詞を変えて、よりかわいく。音作りも変えて」。参考: https://www.youtube.com/watch?v=TN60zc08x04
→ インゲン「カニ カニ カニ。」（2021-07-25、2:51、歌: 琴葉茜・琴葉葵）。VocaDB のタグ「デュエット」「歌うソフトウェアトーク」、
ニコニコの記事見出し「カニダンスが猛烈かわいいボイロソング」「ゆるーい空気感」「心穏やカニなった」。
以前の「ボイロっぽく」は VOICEROID（トーク音声）のことだったと判明。歌詞・旋律・編曲は流用せず、核の 3 点だけ取り入れる:
1) 二人の掛け合い 2) トーク音声に歌わせる声（ボイロ曲の声） 3) ゆるくてかわいい空気と言葉遊び。

## 声: VOICEVOX のトーク音声で歌う（src/song/talksing.mjs）
- `/audio_query` で歌詞の読み（モーラ列）を取り、各モーラの pitch（ln f0）と子音・母音の長さを楽譜で上書きして `/synthesis`。
  無声化を避けるため母音は小文字（有声）に。モーラ数が音符数と合わなければエラー。
- 測定（同じ高さの「ら」×4、周期性と音量）: 使える音域 つむぎ C♯4–A4（＋D♯5）、ずんだもん A4–D♯5、はう F4–D♯5、ニア C♯4–C♯5。
  → つむぎ（低い声部）＋ずんだもん（高い声部、「〜なのだ」のくせ）。VOICEVOX の定番コンビを琴葉姉妹の位置に。
- 測定: 0.23 s 以下の音は安定（-20〜-30 dB）、0.47 s の音は息っぽく消える（-36〜-43 dB）。「ー」で伸ばしても、同じ母音を打ち直しても改善せず。
  → トーク部分は音を 0.3 s 以内に切り、残りは休符（capForTalk）。短く弾む歌い方はボイロ曲らしさでもある。
- QA（talkQa）: 音符ごとに 25 ms 窓で ±3 半音内の周期性の中央値と音量を見る（トーク音声は音間を滑らかに移るので、一定の音程は要求しない）。
  フレーズ最後の音は話し言葉の文末のように消えるので前半のみで判定、「ん」は音量を見ない。不合格のフレーズだけ同じキャラの歌唱用の声に自動で差し替え。
  v1 の最終版では差し替え 0 件（無声化しやすい「む」「う」で始まる語や 1 音だけのフレーズは、楽譜側で直した）。

## 曲（songs/ame-ame-ame/score.mjs）
- A メジャー、128 BPM、100 小節 ≈ 3:08。構成: イントロ 8 / A1 16 / サビ 16 / 間奏 4 / A2 8 / サビ 16 / ブリッジ 8 / サビ 16 / アウトロ 8
- 物語: ピンクの空から飴が降る。ずんだもん「ぜんぶ ほしいのだ」、つむぎ「むしばに なるよ」（以前の「毒と甘さ」を虫歯というかわいい毒に）。
  ブリッジは一粒をめぐる小さなけんか（ひとつ わけて / だめなのだ / えー / じょうだんなのだ / はんぶんこ）。
- フック: ずんだもんの淡々とした「あめ あめ あめ。」（同じ言葉 ×3 + 句点の間）。「せーの」で二人がそろってサビへ。
- 和音: サビ A(add9)–E–F♯m7–Dmaj7、A メロ Dmaj7–E–C♯m7–F♯m7（王道進行）、ブリッジ Bm7–E–C♯m7–F♯m7。
- 音作り（EDM 系をやめる）: マリンバ（打ち下ろし + 裏拍の刻み）、丸いベース（サイン + 三角、跳ねる 3+3+2）、軽いキック、
  シェイカー、クラップ、オルゴール（イントロとアウトロでフックを先取り/回想）、チップのリフ（間奏・ラストサビ）、
  スライドホイッスル（場面転換）、おもちゃの効果音。
- 計測: 区間 RMS イントロ -16.6 / A -11.3 / サビ -10.2 / 間奏 -15.1 / ブリッジ -12.2 / アウトロ -14.5 dB、
  低域 6.9%・中低域 25.8%・声帯域 25.8%・8 kHz 以上 0.3%（軽く明るい）。

## v2（「ころん」→「ふわり」、歌わせ方 3 方式の聴き比べ）
フィードバック: 掛け合い・場面が浮かぶ声と歌詞・明るいメロディ・ふわふわ感が好評。つむぎの「ころん」は語呂が悪い。
「読み上げの声で歌わせる」とは何か、ほかの方式と聴き比べたい。

- 歌詞: ころころ ころん → ふわふわ ふわり、てのひらに ころん → てのひらに ふわり、もう ひとつ ころん → もう ひとつ ふわり
  （モーラ数が同じなので旋律はそのまま。語尾の「ん」は鼻音で弱く、トーク音声では特に消えやすかった）。
- `node bin/song.mjs produce <dir> --mode talk|sing|hard` で歌わせ方を切り替え（ページには方式名つきで並ぶ、インストは 1 本だけ）:
  - talk: トーク音声（読み上げ用の声）に 1 モーラずつ音高と長さを指定（ボイロ曲の声。短い音、音間の滑らかな移り）
  - sing: 歌唱用の声。波音リツ（歌唱指導）の抑揚をつむぎ / ずんだもんの歌声で。softTune（揺れ 50% 残し）。長い音もそのまま歌う
  - hard: sing と同じ声で、音程を各音符に貼り付け（機械的なボカロ風）
- 3 方式の音量は揃っている（A -11.2〜-11.3 / サビ -10.3 dB）。talk 方式の差し替え 0 件。
