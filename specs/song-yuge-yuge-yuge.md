# 曲「ゆげ ゆげ ゆげ。」: お風呂で、音が自然に加わって音楽になっていく二人の歌

## 経緯（探索「ふたりの音」の評価、2026-10-22）
`specs/explore-duo.md` の 26 本にユーザーが ★ とメモをつけた。
- ★5: ゆめごこち（fluffy-3）「お風呂で歌っているみたい。心地よい鼻歌から、歌詞の無い楽器のメロディ、そこにずんだが加わって、
  桶をたたく音やお風呂を沸かすボタンのピッという音など、音が自然に加わって音楽を形作っていく発展の音楽は非常に深く没入するだろう」/
  1 語ずつ交互（二人の仲の良さ。ここぞという場面や入りで使えそう。ただし途中でずんだもんの発音が消えかけた）/
  ウクレレ（体が揺れて足がステップを刻みそう）/ つむぎ × ずんだもん。
- ★4: ふかめ（壺の底から二人の声を聴いているみたい → 「ずんだが拾った壺の底から外の光を見る」曲のアイデア）/ こだま・3 度
  （さわりのイヤーワーム強調に）/ 最後だけユニゾン（重ねた響きが美しく鳴れば）/ トイピアノ（はじける感じ）/ はう（ずんだとの組み合わせ）。
- ★3: 交互、音痴の量 4 本すべて、チェレスタ、カリンバ、テープ、ニア × ずんだ、ニア × はう。
- ★1: さっぱり（声の主張が強すぎる）、輪唱、ハープ（音が合わない）、雨音。

→ ★5 のメモ（お風呂・発展の音楽）を曲の骨格にし、ほかの ★5・★4 の要素を役割ごとに配置した。

## 消えかけた音の原因（測定）
`talkQa` に音ごとの音量（フレーズ中央値からの差）を返させ、`produce` が 9 dB 以上沈んだ音を一覧で出すようにした。
1 語ずつ交互のずんだもん: 「**ふ**るね」-10、「のき**し**た」-9、「**く**るのだ」-10 dB（ほかにつむぎ「**し**と」-11 など）。
→ 無声子音＋「い/う」（し・ふ・く・す・つ・ち・ひ…）は読み上げ声で沈む（無声化の名残）。ずんだもんの言葉からはこれを外した。
（鼻歌の「ふ」は検査も合格、-10 dB は鼻歌として自然なので残した。）

## 曲（songs/yuge-yuge-yuge/score.mjs）
A メジャー 128 BPM、64 小節 = 2:00（書き出しは余韻込み 2:04）。音響は「ゆめごこち」（リバーブ 1.1 / room 0.95、2 分音符のトレモロ深さ 0.8、
コーラス 0.7、高域 -5 dB）。ウクレレだけはリバーブにもトレモロにも入れず、ノリを前に出す。

| 部分 | 小節 | 和音 | 何が加わるか |
|---|---|---|---|
| bath | 4 | A–D | 「ピッ ピッ」（パネル）としずく（A ペンタトニックに調律、拍に乗らない）、パッドだけ |
| hum | 8 | A–D | つむぎの鼻歌「ふんふん ふふーん」（歌より 2.5 dB 小さく）、ビブラフォン |
| toy | 8 | A–D | トイピアノが同じ節を言葉なしで（さわりの形を先取り）、つむぎが「ふふーん」と相づち、桶が 2 回、丸いベース |
| enter | 8 | D–E–C#m7–F#m7 | ずんだもん「ざぶん なのだ」で登場、フレーズの問いと返事、桶が 2 拍目に → 最後に二人で「せーの」 |
| verse | 8 | 同 | 1 語ずつ交互（★5）、ウクレレのストローク（★5）、軽いキック、桶が 2・4 拍、しずくが 8 分裏の刻みに |
| hook | 8 | A–E–F#m7–D | ずんだもん「ゆげ ゆげ ゆげ。」→ つむぎが最後の「ゆげ」を 4 度下で小さくこだま（★4）→「ほわほわ」、2 行目は 3 度で重なる（★4） |
| tile | 4 | Bm7–E | 間奏: 「ピッ」がさわりの形を弾き、トイピアノとしずくが答える。つむぎの鼻歌 |
| hook2 | 8 | A–E–F#m7–D | 最初から 3 度で重なるさわり、トイピアノが上で |
| end | 4 | D–E–A–A | つむぎ「あがろうか」ずんだもん「まだ はいるのだ」→ 二人で「ゆげ ゆげ ゆげ。」を 3 度で、最後の「げ」だけ同じ A4（★4 のユニゾン） |
| outro | 4 | A–D | しずくと鼻歌に戻り、最後に「ピッ」 |

歌詞（つ = つむぎ、ず = ずんだもん）
- enter: (ず) ざぶん なのだ (つ) おゆが こぼれた / (ず) あわあわ なのだ (つ) ほわほわ だね / (ず) あわで あらうのだ (つ) めに はいるよ / (ず) めを とじるのだ / (ふたり) せーの
- verse: (つ) あわを (ず) たてるのだ / (つ) あわが (ず) もこもこ / (つ) おでこに (ず) のせる / (つ) かんむり (ず) なのだ /
  (つ) にあうね (ず) おうさま / (つ) おなじ (ず) なのだ / (つ) ゆげが (ず) のぼるのだ / (つ) てんじょう (ず) まで
- hook: (ず) ゆげ ゆげ ゆげ。 (つ) ゆげ … ほわほわ / (ふたり) まどが ぼんやり / (ず) ゆげ ゆげ ゆげ。 (つ) ゆげ … ぬくぬく / (ふたり) のぼせ そうなのだ
- end: (つ) あがろうか (ず) まだ はいるのだ / (ふたり) ゆげ ゆげ ゆげ。

フックは「あめ あめ あめ。」と同じ型（同じ語 ×3 + 句点の間）。「ゆ」「げ」はどちらも有声で、読み上げ声で沈まない。

## 追加した機能
- `src/song/synth.mjs`: `drip`（しずく「ぴちょん」: 音程へ 20 ms で上がる正弦波＋小さな 2 粒目、調律可）、`bucket`（桶「カコン」: クリック＋2 つの胴の共鳴、
  「コーン」は部屋のリバーブ）、`beep`（「ピッ」: 正弦波に少し矩形波、90 ms）。
- `src/song/produce.mjs`: セクションの `lines`（楽器の旋律を歌と同じ記法で: トイピアノ・しずく・ピッ・桶）、`comp` に複数指定、
  ドラム `bath`（キック＋桶が 2・4 拍＋シェイカー）/ `bathLight`（桶が 2 拍目だけ）、`stats.weakNotes`（沈んだ音の一覧）。
- `src/song/talksing.mjs` 側は変更なし。`talkQa` が音ごとの `rows`（音量・周期性・中央値からの差）を返す。
- `src/song/tokens.mjs`: 移調と 3 度下のハモり（音域を外れるところは 6 度下）を曲から使えるように（explore-duo から移動）。

## 測定
- 読み上げ声の差し替え 0 件。沈んだ音（-9 dB 以上）: 鼻歌の「ふ」-10、ハモりの「ぼんやり」の語尾「り」-11（フレーズ末で話し言葉のように消える）。
  初版の「おそろい」の語尾「い」-13 は「おなじ」に替えた。
- 音程のずれ: そのまま 中央値 39 セント・50 超 42%・100 超 15%（n=305）、音痴 中 32・30%・2%。
- 部分ごとの音量（dB RMS、全体 / 伴奏だけ）: bath -26.5 / -22.0、hum -13.7 / -18.8、toy -15.5 / -13.0、enter -9.5 / -12.3、
  verse -8.9 / -10.7、hook -9.7 / -9.9、tile -12.9 / -10.7、hook2 -9.6 / -9.8、end -10.3 / -12.2、outro -16.4 / -20.2。
  伴奏は浴室から段階的に厚くなる。初版は鼻歌が声だけ前に出ていた（全体 -12.7 / 伴奏 -18.7）ので鼻歌を -2.5 dB、浴室を少し上げた。
