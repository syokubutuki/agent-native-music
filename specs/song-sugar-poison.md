# 曲「シュガシュガポイズン」: 「ヴァンパイア」系エレクトロ・ダンスポップとして完成させる

## 経緯
「ぜんぶちょうだい」（g0003-01 の生成ノイズ伴奏 + VOICEVOX）は不採用: 伴奏が音楽の形を持たない、「ちょうだい」の語呂が悪い。
ユーザー指示: DECO*27「ヴァンパイア」の雰囲気と音楽設計を取り入れ、既存の伴奏は使わず、音楽として完成させる。歌詞は変更。

## 参照した事実と、取り入れたもの（旋律・歌詞・コード進行は流用しない）
- 「ヴァンパイア」: 164 BPM / 4/4 / C♯ マイナー（RemyWiki, ChordWiki）。→ 同じテンポ・調性感
- 作法（ジャンルとしての一般的な特徴、資料による裏付けは無し）: 四つ打ち、跳ねるオクターブのシンセベース、
  裏拍のスーパーソー・スタブとサイドチェイン（ポンピング）、反復する楽器リフ、機械的に音程を貼り付けたボカロ的な歌、
  プリコーラスのビルドアップ（スネアロール + ライザー）からサビで解放、サビ後のリフ・パート、ブリッジで一度落とす。

## 曲（songs/sugar-poison/score.mjs）
- 164 BPM, C♯m, 116 小節 ≈ 2:53。声: VOICEVOX 櫻歌ミコ（ノーマル）, ハードチューン。サビは自然な抑揚の声を左右にダブル。
- 構成: イントロ 8 / A1 16 / B1 8 / サビ 16 / リフ 8 / A2 8 / B2 8 / サビ 16 / ブリッジ 8 / ラストサビ 16 / アウトロ 4
- コード: サビ A–B–G♯m–C♯m（王道進行の短調側）、A メロ C♯m–A–E–B、B メロ F♯m–G♯m–A–B、ブリッジ A–A–F♯m–G♯
- リフ: 1 小節のリズム型を固定し、各小節のコードトーン（根音/3 度/5 度/オクターブ）に当てはめる → 型は同じで和声に追従
- 歌詞フック: 「シュガシュガ ポイズン」（破裂音 + 反復、テーマ「毒と甘さ」）。「もういっかい」で終わり、繰り返しを誘う。
  ユーザーの行（やさしいふりが いちばんこわい / ぬるいこたえは いらないの / きみのさいごまで わたしのもの / ぜんぶあげるから）を残す。
- 歌唱用の表記: 助詞「は」は「わ」で歌わせる（表示の歌詞は「は」）。

## 音作り（src/song/synth.mjs, fx.mjs, produce.mjs）
- 楽器: キック（ピッチ下降サイン + クリック）、クラップ（3 連の帯域ノイズ + 残響）、ハット（高域を 12.5 kHz で丸める）、
  ベース（デチューン saw ×2 + サブ、フィルタエンベロープ）、スーパーソー（5 声デチューン, stab / pad）、プラック、ライザー、インパクト。
  saw/square は PolyBLEP でエイリアシングを抑える（耳に痛い高域を作らない）。
- ミックス: 各ステムを目標 RMS に合わせる → サイドチェイン → 声の帯域（2.5 kHz）をコード楽器から -3 dB →
  区間ごとの音量カーブ（A メロ 0.6、B メロで 0.7→0.95、サビ 1.0、ブリッジ 0.45→0.9）→ リバーブ/付点 8 分ディレイ → マスター。
- 計測（v1）: 区間 RMS イントロ -16.5 / A -12.2 / B -11.2 / サビ -10.0 / ブリッジ -12.0 / ラスト -9.9 dB。
  帯域比 低域 22% / 中低域 29% / 声帯域 13% / 8 kHz 以上 0.3%。ピーク -1 dBFS。
