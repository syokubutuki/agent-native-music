# 曲「ふわ ふわ ふわ。」: 二人の冬の夜の子守唄（読み上げ音声の掛け合い・第 2 曲）

## 依頼と狙い
「あめ あめ あめ。」とは違う場面・季節・テンポで、つむぎ × ずんだもんの新曲を 1 曲。最優先は
1) 二人のやり取りを聞き続けたくなること 2) 柔らかく「ほわんほわん」した音響 3) ふわふわした言葉 4) 場面が浮かぶこと。
スキル（`.claude/skills/talk-duet-song/SKILL.md`）の好み・没案を前提にした: セリフや台本の演出なし、音程補正なし、早口なし、
声のスイートスポットより高い旋律なし、「ちょうだい」「ぽとり」などの没ワードなし。

- 場面: 初雪の夜。窓の外に雪 → ふとんを並べる → 雪の音に耳をすます → あしたの雪だるまの相談 → 夢の中へ → おやすみ。
- 季節・テンポ: 冬・子守唄 86 BPM（あめ: 春っぽい飴の雨・128 BPM）。調も変える: D メジャー（あめ: A メジャー）。
- フック: ずんだもんの「ふわ。ふわ。ふわ。」。同じ語 ×3 ＋ 間、という好評だった型はそのまま、間を語のあいだに入れて
  4+2 / 4+2 / 4（16 分）の揺りかごのリズムに。一つずつ「ふわ」が雪のひとひらのように消える。
  「ふわり」は雨に合わないという理由で没だったが、雪とふとんには合う（言葉そのものはユーザーが「好き」に挙げた「ふわふわ」）。
- 掛け合い: A メロはつむぎが気づき・ずんだもんが「〜なのだ」で応える交互。サビはずんだもんのフック → つむぎの返し →
  二人で 3 度ハモり。ブリッジは「こだま返し」（スキルの未検証案）: つむぎの一節をずんだもんが 4〜5 度上でなぞり、最後に二人で
  「おなじ ゆめ みよう」。ラストサビとアウトロではつむぎがフックを 6 度下で重ねる（ハモり）。

## 曲
- D メジャー、86 BPM、64 小節 ≈ 2:59（尾 2 小節込み 3:04）。
  構成: イントロ 4 / A1 12 / サビ 8 / 間奏 2 / A2 8 / サビ 8 / ブリッジ 8 / サビ（ハモり）8 / アウトロ 6
- 音域: つむぎ D4–A4（導音 C♯4）、ずんだもん A4–D5。測定済みの使える音域（C♯4–A4 / A4–D♯5）の中で、どちらも主音を持てる調。
- 和音: サビ Gmaj7–F♯m7–Em7–Dadd9（IV–iii–ii–I、根音が 1 段ずつ下がって沈んでいく）＋後半 …Em7–A。
  A メロ Dmaj7–Gmaj7 の揺れ（I–IV）から Bm7–Em7–Gmaj7–A。ブリッジ Bm7–F♯m7–Gmaj7–Dmaj7–Em7–F♯m7–Gmaj7–A。
- 旋律はすべて 8 分（86 BPM で 0.35 s）。フレーズの途中に長い音・16 分を置かない（テストで固定）。
- 音作り（`meta.mix`）: ビブラフォン（1・3 拍）に 4 分音符同期のトレモロ 1.43 Hz・深さ 0.55 =ゆっくりした「ほわん ほわん」、
  パッドとビブラフォンにコーラス、声のリバーブ 0.6（room 0.9 / プリディレイ 40 ms）、楽器リバーブ 0.55、6 kHz 以上 -3.5 dB（夜の暗さ）。
  オルゴール: イントロ・間奏・A1 の終わり・アウトロでフック、サビとブリッジで和音のアルペジオ。ガイド（歌メロを小さくなぞる）あり。
  打楽器はサビだけ: 新しいドラム型 `nenne`（1 拍目の心拍のような軽いキック＋ささやくシェイカー、クラップなし）。
  ベース: 丸いベースで全音符（`long`）、サビは新しい型 `sway`（根音 → 1 オクターブ上、揺りかご）。
  おもちゃの効果音は新しい型 `snow`（4 小節に 1 度、遠くできらっと）だけ。スライドホイッスル・チップのリフは使わない（子守唄に騒がしい）。

## 判断の記録
- **遅いテンポで読み上げ声が持つか**: 86 BPM の 8 分は 0.35 s で、測定済みの安定長（0.23 s 以下）を超える。
  - 既存の `capForTalk` は、8 分が上限 0.3 s を超えると「8 分 + 長さ 0 の休符」に分けていた。長さ 0 の休符でフレーズが 1 音ずつに
    ちぎれる（1 音のフレーズは弱くなる）ので修正: 8 分は上限を超えてもそのまま歌う（`test/song/fuwa.test.mjs`）。
  - talksing は 0.24 s を超える音を「ふ ー」の 2 モーラに分ける。モーラ上限 0.4 s（分けない）とも比べたが、QA の合否は同じ
    （`talkQuery` に `maxMoraSec` を足して実験。既定は 0.24 s のまま）。
  - QA 不合格は書き出し 1 回目で 12 フレーズ。同じフレーズを 100 / 128 BPM で歌わせると 128 BPM では全部合格、100 BPM で一部不合格
    → 原因はテンポ（音が長いほど語中の母音が崩れやすい）。テンポは子守唄のまま、言葉と旋律で直した。
- **不合格だった言葉と直し方**（今後の参考。どれも語中の音が数 dB〜20 dB 落ちるか、音程が 3 半音以上外れて周期性が下がる）:
  - 「なにか きこえるのだ」の「え」（5 半音外れ）→ 旋律を変えて合格（き:C♯5 こ:B4 え:B4）。
  - 「ふとんに もぐろう」の語尾「う」（-46 dB、ろ+う が伸ばし音に溶ける）→「ふとんに くるまる」。
  - 「そりにも のるのだ」の「る」→「そりにも のりたい」。「まだ ねないのだ」の「ね」→ 音程を入れ替えて合格。
  - 「おおきいのに しよう」の「き」→「おおきく つくろう」。「じゃあ はやく ねよう」の「は」→「じゃあ もう ねようね」。
  - 「そらを とぶ」（つむぎ）の「ら」→ 旋律を F♯4 F♯4 E4 F♯4 D4 に。「ゆきの うえ」（ずんだもん）の「う」→ 二人とも「ゆきの はら」。
  - 「おやすみ ずんだもん」の「ず」→「おやすみね ずんだもん」（「ね」がはさまると「ず」が立つ）。
  - 結果: talk fallbacks 0 件（外れ方そのまま / 音痴 中 の両方）。
- **音痴の量**: そのままだと中央値 55 セント・半音以上 15%（あめの v4 計測 35 セント・12% より外れる。ずんだもんの跳躍が縮む ±80 セント級）。
  音痴 中（`--heta mid`）で 34 セント・4% ＝あめの「そのまま」に近い。ユーザーはまだ最終的な度合いを決めていないので 2 本並べた。
  中ではフックの「ふわ」15 フレーズが歌い直しで QA に落ち、元のテイクのまま（短い 2 音フレーズは補正に弱い）。
- **ミックスの調整**（計測、聴取なし・推定）: 1 回目はイントロが A メロより 10 dB 小さく、インストの 150 Hz 以下が 31.5% と重かった
  → イントロのレベルを上げてベースを入れ、丸いベースを -16 → -18 dB。最終: 区間 RMS イントロ -16.4 / A -11.8 / サビ -11.1〜-10.5 /
  間奏 -17.1 / ブリッジ -11.4 / アウトロ -13.4 dB。帯域比（フル）150 Hz 以下 9.9%・150–500 Hz 13.1%・0.5–4 kHz 41.5%・8 kHz 以上 0.6%。
- **試聴ページ**: 過去曲の WAV はリポジトリに無い（`songs/**/*.wav` は git 管理外）ので、新しい環境では `lab page` が止まっていた。
  `node bin/lab.mjs page --reuse <公開中の index.html>` を追加: ディスクに無い曲の項目は公開中ページの項目（音声パス・波形）を引き継ぎ、
  グループの並びも公開中ページの順を保って新しいグループを先頭に置く。送るのは新しい MP3 だけ。
