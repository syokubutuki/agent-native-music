# ロードマップ(歌入りの曲を作る)

目標: ボカコレで繰り返し聴かれる、歌声合成の歌入りの曲。聴く場所はこれまで通り、ダウンロード不要のブラウザ試聴ページ。

## 方針(2026-10-21 決定)
- 歌声は **A(あなたのPCの歌声合成ソフト)を主軸**、**B(無料の歌声AIをクラウドで動かす)を時間を区切って試す**。C(有料のAI作曲サービス)は規約と費用を確認してから。
- 歌い手は既存の歌声ソフトのキャラクターを使う(利用規約は個別に確認)。
- 最初に雰囲気の違う3曲の案を作り、聴き比べて型を決める。過学習を避けるため、1曲を直し続けない。

## 調べて分かったこと
- クラウド環境から PyPI と Hugging Face には接続できる。GitHub(リリースの配布物)は接続できない。GPU はなく CPU のみ(4コア / メモリ15GB)。歌声AIを動かす場合は、声の素材の入手と利用ルールが課題になる。
- ボカコレの最新規約(特にAI関連)は検索では確認できなかった。**投稿前に公式の規約を確認すること。**

## 段階
1. 好みの法則を整理する(`docs/taste.md`)。済。
2. 3曲の案を作る。メロディ(歌の旋律)と伴奏と歌詞を、別々に聴き比べて選べるようにする。
3. 楽譜データに「歌のパート(旋律+歌詞)」を足す。歌声ソフトに渡せる形式で書き出す(使うソフトが決まってから形式を選ぶ)。
4. 歌声を付けた試作を作り、ブラウザで聴く。
5. 1曲を完成させる。規約確認、投稿準備。
