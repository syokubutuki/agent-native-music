# 好みの法則(「雨の窓辺」v1〜v5 の感想から)

次の曲づくりの前提として使う。出典はすべて試聴ページの感想(`notes` コレクション)。好き度は 1〜5。

## 好きだったこと(根拠つき)
- **変化の瞬間が気持ちいい。** ドラムが入る場面を「最高に気持ちいい」と評価(v2、好き度5)。曲の価値は音色の良さより「場面が変わる瞬間」にある。
- **薄い → だんだん厚くなる流れ。** 最初は簡素・軽く、徐々に分厚くなるのが良い(v2)。
- **どんよりは重くてよい。** 「どんよりは今のままでよい」(v3)。重さは足りている。
- **のんびり聴き続けられる穏やかさ。** 「穏やかに溶け出す感じの方向で行きたい」(v1)。
- **明るさは広がりと温かさで出す。** 軽く高い音は「軽く感じる」と不評(v3)。ベースの深さ、広がるパッド、きらめきの組み合わせは「これでよい」(v4、v5)。

## 避けること
- **高すぎる音。** 予感の部分が高すぎた(v4)。目安は、どんよりのメロディと同じ高さまで。
- **新しい場面を足すことで盛り上げる。** 予感は場面ではなく、既存のメロディの中に晴れ間のフレーズを小さく混ぜる形が正解(v4 の指摘)。
- **場面転換が急なこと。** 切り替えの前に、次の場面の素材をそっと先出しする(v3 の指摘)。

## 歌詞・曲の方向(2026-10-21 以降)
- **ボカラップが好み。** 「ぜんぶ すうじ」のラップ部分(1小節に最大16音の超高速、同じ高さで言い切る)は「とても良い」。ボカラップという文化も含めて好み。
- **曲の速さは高速で、キレがよいほうがよい。** テンポ188前後。
- **歌詞の題材が数字なのは微妙。** ラップの型は残し、題材は変える。
- **冗長な曲は飽きる。** 「こえは ぜんぶ あげる」(7拍子、約76秒)は冗長で飽きた。短く詰める。
- **「平均的なよいこ」な歌詞は不可。** 風景、励まし、ぬくもり、涙のような定番は避ける(v1〜v5 の後の指摘)。
- 計測の結果(`tools/rhyme.mjs`): 好評だったラップ部分は、語尾をそろえる韻は薄かった(語尾の一致 0.17)。効いているのは韻ではなく、**速さと言い切りの流れ(フロー)**。韻は付け足しの要素として扱う。

## まだ分からないこと
- 先ぶれが「小さい」と感じられる適量(v5 で試した、感想待ち)。
- 歌が入ったときの好み(声の高さ、歌詞のテーマ、歌い手)。
- ほかのジャンル(速い曲、バラード)にもこの好みが通じるか。1曲だけの傾向である可能性がある。
