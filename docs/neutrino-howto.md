# 歌声の付け方(NEUTRINO)

## なぜクラウドの私は声を付けられないか
NEUTRINO の利用許諾契約書(2026/08/21 改定版、[公式ダウンロードページ](https://studio-neutrino.com/downloads/)の「利用許諾契約書(EULA)」)の禁止事項に、次がある。
- 本システムの全部または一部を、製作者の許可なく転載、再配布、**第三者へ提供**する行為。
- 歌声ライブラリを、本システムを介さずに利用、または第三者へ提供する行為。
- Neutrino Orbit(Web版)への**大量の自動アクセス**や、利用制限の回避。
- 出力した音声・中間データを、AI・機械学習による歌声合成・音声変換などの**学習データや入力音声**に使うこと。

クラウド環境のコンテナは第三者の運用なので、そこへ NEUTRINO を置いて動かすのも、Orbit を自動で叩くのも、これらに当たるおそれがある。なので、**声を付ける作業はあなたの手元(自分のPCか、公式のOrbitを人の手で)で行う**。ライセンスの同意も、各歌声ライブラリの利用規約の確認も、あなた自身がすること。

## 手順
1. 楽譜(MusicXML)を取る: `exports/musicxml/` の次のファイル。
   - `sketch-j-utsuranai-v1.musicxml`(歌・ラップ)
   - `sketch-j-utsuranai-v1-part2.musicxml`(合いの手)
2. NEUTRINO に読み込ませて、歌い手(歌声ライブラリ)を選び、WAV を書き出す。楽譜のテンポは曲の元のテンポ(うつらない=164)が入っている。
   - 歌詞はすべてひらがな、1音1文字。小さい「っ」と伸ばす「ー」は使っていない。
   - 最初に読み込めない、または音域が合わないときは、そのエラー文を私に教えてほしい。
3. 試聴ページの「歌声を重ねる」で、WAV を選ぶ。曲に重ねて鳴り、仮の電子音の歌メロは自動で消える。
   - 声が曲とずれていたら「声のずれ補正」で合わせる。
   - 「ページに保存」を押すと、次に開いても自動で読み込まれる(ブラウザの中で小さい webm に変換して保存する)。

## 注意
- 出力した WAV を、他の AI の音声ツールに入力しない(上記の AI の禁止事項)。
- 歌声ライブラリごとに、クレジット表記や使える内容の条件が違う。ボカコレに出す前に、使うライブラリの規約を確認する。
- 試聴ページでテンポつまみを動かすと、声の高さも一緒に変わる(元のテンポのときだけ、書き出したままの声で聴ける)。
